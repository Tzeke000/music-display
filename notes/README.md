# Music Display — Project Vault

This `notes/` folder is the project's **memory**. It is plain Markdown, so it
opens directly as an [Obsidian](https://obsidian.md) vault: in Obsidian choose
*Open folder as vault* and point it at this `notes/` directory. Wikilinks like
[[02-architecture]] work there.

Because Claude Code on the web runs in an **ephemeral container** (wiped when
the session ends), anything worth remembering across sessions must be committed
to the repo. These notes are that durable memory — both for you and for Claude
in future sessions.
