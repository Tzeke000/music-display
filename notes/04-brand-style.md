# Brand & Style — Tzeke000 Studios

Captured from the artist's site repo (`Tzeke000/Tzeke000.github.io`) so the
visualizer matches the existing identity.

## Identity
- **Name:** Tzeke000 Studios
- **Genre / mood:** Future Bass · EDM · Pop — bass-forward, energetic, neon.
- **Aesthetic:** dark neon / electronic, glassmorphism (blur + subtle white
  surfaces), rounded corners, pill buttons, soft neon glow shadows.

## Palette
| Token   | Hex       | Use |
|---------|-----------|-----|
| bg      | `#07070d` | near-black background |
| bg-2    | `#0d0d18` | panels |
| magenta | `#ff2d95` | primary accent / record |
| violet  | `#8b5cff` | mid accent |
| cyan    | `#1ad1ff` | links / focus |
| text    | `#f2f2f8` | foreground |
| muted   | `#a3a3b8` | secondary text |

**Accent gradient:** `linear-gradient(120deg, #ff2d95 0%, #8b5cff 50%, #1ad1ff 100%)`

## Type
- Headings: **Space Grotesk** (500–700)
- Body: **Inter** (400–600)

## Implication for the visualizer
- UI themed to the palette + fonts above (done).
- Placeholder/fallback art uses the magenta→violet→cyan gradient.
- Defaults tuned for **bass-forward** music (strong bass→dissolve, punchy beats).
- Brand logo `public/tzeke000.jpg` used as favicon; candidate for an optional
  video watermark.
