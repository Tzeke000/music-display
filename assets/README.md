# assets/ — source inputs

Raw material for the visualizer and (later) the auto-publisher. Large media
(audio/video) is gitignored; only this layout is tracked, so the folders exist
on every machine even when empty.

- `audio/` — source songs (`.wav` / `.mp3`), one track per render.
- `covers/` — cover / album art (square, high-res). Used as the visualizer image.
- `brand/` — logos, profile art, fonts. Reused across posts.
- `footage/`
  - `gameplay/` — raw gameplay clips (YouTube gaming content).
  - `studio/` — studio / work-in-progress clips (teasers, behind-the-scenes).
  - `talking/` — talking-to-camera clips (artist persona).
